Introduction

01
  • ■ University syllabi present topics linearly, obscuring true conceptual prerequisite dependencies.
  • ■ Students encounter critical learning blockers due to hidden, unstated foundational knowledge gaps.
  • ■ KDG converts flat text into a directed dependency graph using supervised ML & graph theory.

Problem & Solution

02
Problem

Syllabi lack dependency paths, causing poor sequencing. Generative LLMs hallucinate relations with zero verifiable ML metrics.

Proposed Solution

A hybrid system pairing a supervised XGBoost classifier (≥3,000 pairs) with Kahn's Topological Sort.

Objectives

03
  • 1 Train supervised edge classifier on ≥3,000 labeled concept pairs.
  • 2 Compute optimal learning sequence via Kahn's Topological Sort.
  • 3 Detect curriculum bottlenecks & unstated missing prerequisites.
  • 4 Deploy responsive visualizer with student progress tracking.
04

System Architecture & Proposed Workflow

DEFENSE DOCTRINE Core Principle:
“Classifier achieves ~87% F1 on prerequisite prediction; sequence and bottlenecks are 100% deterministic graph math.”

Project Scope

Core Features

06
  • Prerequisite Prediction Evaluates directed dependency probability \(A \rightarrow B\).
  • Topological Sequencing Provably correct, cycle-free curriculum sequence.
  • Bottlenecks & Gaps Flags critical hubs and unstated prerequisites.
  • Progress Tracker Unlocks nodes as prerequisites are marked completed.
